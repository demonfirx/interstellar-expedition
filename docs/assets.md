# Asal aset

- `public/assets/gargantua-reference.*`: gambar referensi yang diberikan pengguna di chat. Digunakan sebagai latar dan kartu Gargantua, dengan efek gerak tambahan. Hak atas gambar mengikuti sumber aslinya.
- `public/models/astro-rigged.glb`: model voxel original yang dibuat di proyek ini, termasuk rig dan dua klip animasi. Source: `src/models/astronaut.js`.
- Pemandangan planet: material CSS yang dibuat di proyek ini.
- Ambient: sintesis osilator Web Audio, tanpa rekaman eksternal.
- Ikon: Lucide, lisensi ISC.
- Font: Manrope dan Roboto Mono dari Google Fonts, lisensi SIL Open Font License.
